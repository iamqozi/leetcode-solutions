# LeetCode Solutions in C++

My practice journal for learning data structures, algorithms, and problem solving in C++.

## Practice workflow

1. Open a problem and try it independently for 20–30 minutes.
2. Write down the approach before coding.
3. If stuck, use a hint, then try again.
4. Submit on LeetCode and check the result.
5. After acceptance, save the solution and explain its time and space complexity.
6. Record any help used and revisit the problem independently.

## Learning order

Arrays → Strings → Hash maps → Linked lists → Stacks → Binary search → Trees.

Folders are added as I start each topic. Problems use paths such as
`arrays/0001-two-sum/`, containing `solution.cpp` and `README.md`.

## Progress

See [the progress tracker](PROGRESS.md). Starter files are unfinished exercises;
a problem is marked accepted only after a successful LeetCode submission.

## New problem checklist

- Create a topic/problem folder.
- Copy [the explanation template](templates/explanation.md) into its README.
- Add the C++ solution.
- Update the progress tracker.
- Use a descriptive commit message, such as `Add accepted Two Sum solution using a hash map`.

LeetCode solution files use its supplied class/function interface. They do not
include a standalone `main()`; running them locally requires a separate test driver.
